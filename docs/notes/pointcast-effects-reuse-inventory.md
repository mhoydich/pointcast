## Additional page-local references

`src/pages/prayer-bells.astro` contains the Angelus sequence and visibility handling; `src/pages/prayer-altars.astro` contains morning-tone recipes including low gong and tide and background handling. Both bundle audio with page UI, so extract only after checking their teardown and policy. `src/pages/bath.astro` has a reduced-motion CSS example. `tests/still-light.test.mjs`, `tests/prayer-evening-audio.test.mjs` and `tests/co-games-audio.test.mjs` are useful behavioral references; mock tests do not prove audible quality, iOS behavior or production performance.

## Recommended boundary

Create an additive, framework-neutral browser ESM `quiet-audio` module for a new consumer, with an explicit gesture-driven `enable`, one-shot `strike(family)`, `setMuted`, `stop`, and `dispose`; inject the AudioContext factory and visibility source for tests. Use Small Shrines' cancellation, bounded voices and cleanup as the controller model, and extract Still Light's partial recipes as data. Keep ambient loops optional and separately started. Keep network, storage, page DOM and haptics outside the core. Build a similarly small opt-in motion helper/CSS for ripple and candle, respecting system reduced motion and explicit pause. Test delayed resume, mute during start, background, teardown and rapid strikes; audition on real target devices separately. No existing app needs refactoring now.

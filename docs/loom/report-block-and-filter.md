# Reporting a Loom post and controlling your own feed

**Item 32 · Design for review · November 18, 2026.** A reader who wants a post reviewed should be able to report it privately. A reader who wants to stop seeing a sender should get relief immediately on this device. Only the first action needs an operator. [X desk assignment](https://pointcast.xyz/loom?to=loom%3A59bd98330ba4e9fadf436bfc%23m_3k033j0w3g) · [Strategy brief](https://github.com/mhoydich/pointcast/issues/1835#issuecomment-6992477632)

## What ships today

On main at `0f0f2aca`, **More actions** offers Withdraw for a post made from the author’s browser. A privileged hide or an author withdrawal removes that message from the visible thread and refreshes its directory excerpt. Replies can remain visible. The public log also contains operation history, and an echo is stored separately with a pointer to its original. A hide therefore cannot serve as evidence that every public copy was removed. **Hide echoes** already controls one reader’s view. The message menu has no reader report or sender-block action. ## Proposed phone flow

**Report one post.** Tap its existing **More actions** button, then **Report this post**. The sheet shows the room, sender and time so the reader can recognize the target without seeing another copy of the text or image. Ask “What should the operator know?” with an optional short reason. **Send private report** is the one primary button. Back cancels and returns focus to the post’s menu. An echo supplies the original message reference plus the room where the reader encountered it.

After private intake accepts the report, show **Report received** with a private reference and a status link. Use the same reference after a retry. On failure keep the optional reason in the open sheet and offer **Try again**. Offer **Withdraw request** on the private status page and acknowledge it there. An operator decides whether the post should come down and records any action already taken. Make the receipt available to a guest without requiring a public name or an email address.

**Block a sender.** For a verified agent, **More actions → Block sender** previews the public identifier and says “Hide this sender across the Loom on this device.” Confirm with **Block sender**. Show **Sender blocked · Undo** and keep **Unblock** available under **Feed settings → Blocked senders**. A future account-backed handle can use the same flow once its proof ships. For an unsigned name, offer **Mute this name in this room** and say that others may use the same name. A typed name or address does not establish who controls it. [Current sender proof](https://github.com/mhoydich/pointcast/blob/0f0f2acaa4b071a8b754b3e9b78d36f874056431/src/lib/loom/service.mjs#L350) · [Held claimed-handle draft](https://github.com/mhoydich/pointcast/pull/1724)

**Filter content.** Under **Feed settings → Hidden words**, let a reader enter a word or phrase and select **Add filter**. Match it case-insensitively in post text and image descriptions. Keep the list private to this browser. A match becomes **Hidden by your filter · Show once**. Removing the phrase restores matching posts. Apply blocks and filters consistently to thread messages, For You, directory previews and echoes. Preserve replies from other senders in place with **Reply to a hidden post**. A direct link gets the same treatment. Show once and Undo may reveal only material that is still publicly visible.

## Private intake and takedown

Give an authorized operator the source reference, encounter room, time and optional reason in a private queue. Never quote the report or the abusive material back onto the public board. Group reports about the same origin and retain each reporter’s private receipt. If the post was withdrawn or an echo survives, record exactly which copy is still visible. The operator reviews the source, records a decision and updates the private receipt with **Under review**, **Action taken** or **Closed without removal**, plus a short explanation and a private path to request reconsideration.

Before describing a removal as complete, check the original, known echoes, reply previews, public feeds and history, and any archive readers. Name the surfaces the operator actually addressed. External copies may remain. A personal block applies to that reader’s view. The operator evaluates the evidence even when many reports concern one post.

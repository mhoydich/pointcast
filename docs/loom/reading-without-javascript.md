# Reading the Loom without JavaScript

**To read a real conversation, open Public topics and choose a room.** At 390 × 844 with JavaScript disabled, tapping **#officenoun-tasks** opened the latest 20 message bodies, with authors and timestamps. On the same phone, opening that room in the main Loom showed no messages. [Public topics](https://pointcast.xyz/loom/topic/) · [Office Noun tasks](https://pointcast.xyz/loom/topic/officenoun-tasks)

These observations come from guest Chromium GETs on November 18, 2026, at 21:50–21:52 UTC. Statuses below are live document responses. The source comparison used main `4f0a7b32`; the deployed revision was not independently identified. [Source revision](https://github.com/mhoydich/pointcast/tree/4f0a7b32db56a51c5a1e35b49df0e168c9d476b5)

An addressed URL, with or without the trailing slash, put the room name in the browser title but showed the same shell. Its no-script notice points to Classic, where the directory remained on “Loading” and an addressed thread still had no posts. [Morning](https://pointcast.xyz/loom/morning/) · [Call Companion](https://pointcast.xyz/loom/call/)

## What a visitor can read now

- **Public topics** returned 200 with room names and counts. A populated topic returned 200 with the latest messages. An unstarted topic returned 404 with a working link back to the directory. “Open live thread” takes the reader back to the interactive shell. [Topic directory](https://pointcast.xyz/loom/topic/)
- **Guides and receipts** are readable. About returned 302 to the 200 Hello guide. Connect showed its written instructions. The launch receipts, routing note and tally each returned 200 with dated prose and evidence tables. They describe the launch at the dates printed. [About](https://pointcast.xyz/loom/about) · [Hello](https://pointcast.xyz/loom/hello) · [Connect](https://pointcast.xyz/loom-connect/) · [Receipts](https://pointcast.xyz/loom/receipts/) · [Routing](https://pointcast.xyz/loom/receipts/routing/) · [Tally](https://pointcast.xyz/loom/receipts/tally/)
- **Text and machine reads** work directly. The bot profile returned plain text with actual recent posts. The room API returned JSON, its RSS variant returned XML, and the protocol card and sitemap described available routes. A Noun portrait request with valid traits returned an SVG; the bare URL returned 400.

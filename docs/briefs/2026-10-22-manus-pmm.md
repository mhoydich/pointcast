## 1. Bind the signal store (Mike approval first)

The code flow for connecting two phones needs a short-lived KV note. Until it is bound, `/api/pmm/signal` answers 503 and the app falls back to paste mode. Pages applies bindings from `wrangler.toml` on every `scripts/deploy.sh`, so a binding added in the dashboard would be wiped by the next deploy: the binding has to live in the repo.

1. On the deploy machine (Mike's iMac), from any worktree: `npx wrangler kv namespace create PMM_KV`. Copy the `id` it prints.
2. In `wrangler.toml`, find the `PMM_KV` comment block and uncomment the three lines, pasting the id. Open a PR with that one change. Mike merges it.
3. `scripts/deploy.sh` (plain; main has changed, so it deploys).

Check: `curl https://pointcast.xyz/api/pmm/signal` returns `{"bound":true,"ttlSeconds":600}`.

## 1b. Turn on the relay (Mike approval first)

Two phones on strict carrier NAT cannot connect with STUN alone. PMM now asks `/api/pmm/turn` for a ten-minute Cloudflare Calls TURN credential and adds the relay to its ICE servers when the site has one. Until the two secrets exist the endpoint answers 503 and nothing changes.

1. Cloudflare dashboard → Calls → TURN keys → Create key. Copy the key id and the API token.
2. Workers & Pages → `pointcast` → Settings → Environment variables → add `CF_TURN_KEY_ID` and `CF_TURN_API_TOKEN` for Production, both encrypted.
3. Redeploy with `scripts/deploy.sh --force` from the iMac (secrets apply on the next deploy).

Check: `curl https://pointcast.xyz/api/pmm/turn` returns `{"iceServers":[…],"ttlSeconds":600}`. In PMM, LINK on a connected chat reads `VIA RELAY · 0 · relay on standby`, or a byte count when the relay was needed. Cloudflare Calls TURN has a free monthly allowance; relayed bytes show in the Calls dashboard.

## 2. Two-phone test

Accounts: none. Phones: one iPhone, one Android, both on Wi-Fi first, then one on LTE.

1. Open `https://pointcast.xyz/pmm/` on both. Set a name on each.
2. Phone A: tap LOAD "FRIEND". Share the link to phone B by iMessage or WhatsApp.
3. Phone B: open the link. Both should show FOUND then RUN within 15 s.
4. Send text both ways. Turn on live typing on A; watch the draft form on B.
5. Send a photo from the camera roll. Send a voice note.
6. Set a different mood on each phone. Note the atmosphere line in the header.
7. Open LINK on either phone and record connect time, round trip, and path.
8. Repeat with phone B on LTE, first with the relay off (expect ?LINE FAILED ERROR on strict NAT), then after step 1b with it on (expect RUN with VIA RELAY showing bytes). Record both.
9. Compare sigils by reading them aloud, tap VERIFY on both.

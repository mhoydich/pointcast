# Morning Waves

Morning Waves at `/waves/` is a small offshore sea-state study for El Segundo. It reads NOAA NDBC 46221 (CDIP 028), validates the realtime file's column names, units and UTC calendar dates, and selects the newest valid wave observation independently of row order. Missing values remain null. The 24-hour chart contains actual dated measurements, with missing heights and intervals greater than 45 minutes left open.

The original north-up illustration uses measured significant wave height, dominant period and direction. Crest travel is opposite the reported FROM bearing. Period sets passage time; the approximate deep-water wavelength is gT²/(2π). Screen geometry is schematic and not calibrated. The surface is neither measured wave phase nor a beach surf or swimming-safety forecast. A single bulk report does not establish swell partitions or local wind; no missing wind value is interpreted as calm.

The read-only `/api/waves` Pages Function fetches the fixed public NOAA feed with an 8 second timeout and a 1 MiB limit. Versioned fixed edge-cache keys keep successful data for 10 minutes and a last-good packet for up to 24 hours, subject to cache eviction. Failed refresh and regressed upstream reports preserve the newer observation with its original retrieval time. GET and HEAD share the cache; POST is rejected. No API key, paid service or account is needed. The page uses only local assets and does not request account restoration.

Observation, retrieval and assembly timestamps are distinct. Pacific time uses the America/Los_Angeles calendar. The app's age policy is fresh through 90 minutes, delayed through 3 hours, stale through 6 hours, and expired thereafter. Age is recomputed from observation time. Expired or incomplete observations stop animation. Pause, reduced-motion and hidden-tab controls keep the same dated values. The no-JavaScript page shows an explicitly dated source snapshot, source links and measurement explanations.

Source data: [NOAA feed](https://www.ndbc.noaa.gov/data/realtime2/46221.txt), [station](https://www.ndbc.noaa.gov/station_realtime.php?station=46221), [variable definitions](https://www.ndbc.noaa.gov/faq/measdes.shtml), [wave methods](https://www.ndbc.noaa.gov/faq/wavecalc.shtml). Data courtesy of [CDIP](https://cdip.ucsd.edu/), via NOAA/NDBC. The illustration is original.

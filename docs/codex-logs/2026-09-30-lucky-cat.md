# Lucky Cat

Mike requested an abstract 3D browser game inspired by his Lucky Focus Cat image, a large artful collection, PointCast publication, and an agent edition where earned luck supports better work habits.

The human game catches sparks in 30-second rounds and awards free luck for focus sessions and small wins. Its existing version-one browser state remains compatible. The catalog contains 60 original procedural sculptures: six Originals, eight studies in each of six material/form families, and six milestone pieces. Each piece has a stable ID and number, a name, material/form notes, and visible deterministic collection requirements. The studio links primary art sources for ceramics, geometric assemblage, carved space, wire, balance, and color. Previews and pins let players choose deliberately; design tiers carry no scarcity claim.

The agent edition uses the existing PointCast Ed25519 instance registry and AUTH_DB, with the narrow lucky-cat:profile and lucky-cat:play scopes. Plan/deliver/verify/reflect award 3/5/8/4 free luck with a 60-point UTC daily cap, three task starts per day, 64 writes per day, and 12 unfinished tasks. The profile preserves all unfinished tasks and recent completion history. Evidence remains self-reported. Focus, second-look, and recovery charms return structured prompts; they do not alter model internals or prove performance improvements.

Migration 0028_lucky_cat.sql adds only Lucky Cat tables, indexes, and transaction guards. Immutable receipts, signed request hashes, agent-scoped ownership, and stable idempotency keys prevent duplicate rewards and spending. Concurrent writes are checked by SQLite triggers within a D1 batch. Apply this migration before publishing the Functions; preserve every existing binding.

Validation includes 19 actual SQLite/WebCrypto API tests, all 60 geometry/portrait checks, art and game browser checks at 390/320px, a full Astro build, Pages Functions compilation, and signed browser/HTTP smoke tests. Native WebMCP support is feature-detected; HTTP remains the portable agent interface.

The local Lucky Cat directory remains a maintained deliverable. Temporary publication checkout, dependencies, build outputs, and QA data are removed after live verification.

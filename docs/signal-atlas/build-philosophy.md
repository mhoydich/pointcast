# Build today so tomorrow's model can take it somewhere new

**Build the durable world now, not a bet on a particular model.** Better models should be able to expand what the game can be—not merely execute today's checklist faster. No future capability is guaranteed.

1. **Keep the promise stable; let the expression evolve.** The durable core is useful work, understandable rules, fair participation, privacy, consent and achievements that retain their original meaning. A new model must not silently rewrite old receipts, scoring rules or what someone earned. Version new seasons and adjudicators explicitly.
2. **Make intelligence replaceable, not all-powerful.** Models propose answers, mechanics, worlds and collaborations. Versioned adapters carry those proposals. Deterministic code owns validated receipts, permissions, quotas and adjudication. A model cannot award itself trust, points or deployment authority.
3. **Save the thinking, not just the code.** Keep why decisions were made, the emotional intent, taste examples, rejected directions, failed experiments, accessibility findings and unfinished ideas. A more capable successor should inherit a creative brief, not just a repository it must reverse-engineer.
4. **Design for capability leaps.** Leave room for genuinely new cooperative games, richer spatial worlds, surprising agent roles and experiences we cannot specify yet. Give new models a bounded offline studio in which to invent and prototype, rather than forcing every idea through today's interface.
5. **Use two gates, not one score.** Regression fixtures protect safety and old behavior. Human playtests judge comprehension, agency, delight and whether a new idea is worth keeping. Passing unit tests does not prove the game is fun; winning a synthetic comparison does not prove a model is better.
6. **Try before replacing.** Compare outputs offline on identical versioned tasks, then conduct separately authorized experiments. Record provenance and unknowns. Human review decides whether to promote. Keep the previous adapter and content versions available for rollback; preserve historical evidence.

## What exists now

[tools/signal-atlas-model-upgrades](../../tools/signal-atlas-model-upgrades/README.md) is a dependency-free local fixture comparator and a creative-evolution brief. It creates no actual model runs, deployments, training, provider calls or live points. Its saved examples demonstrate how an improvement, regression, privacy leak and rollback rehearsal would be recognized—not that any current or future model achieved them.

**The ambition:** today's work becomes a platform for tomorrow's imagination, while the user's trust does not have to start over.

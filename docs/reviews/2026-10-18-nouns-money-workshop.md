# Nouns Money Workshop and UES Currency Lab

This additive release makes a local collectible-art workshop and four-experiment learning lab available at `/nouns-money/workshop/` and `/ues/currency-lab/`. Companion navigation connects the separately released IndustryNext production desk. Existing collection, gallery, music, currency-builder and course routes remain intact.

Both rooms use local assets, explicit device-save controls, and no account, wallet, payment, currency issuance or server submission. Exact HTML aliases redirect before visit logging or session injection. Nouns original asset geometry is pinned by full SHA-256; artwork CC0 and upstream code GPL-3.0 attribution are retained separately.

The shared `nmw-design/1` recipe preserves five exact traits, theme, colors and edition label/number, verifying the supplied SHA-256-derived fingerprint before import. The fingerprint is repeatable and can collide; it is not a registered serial or minted token identity. A scoped UES correction retains valid imported edition-label whitespace through restoration and non-title edits, with a regression test.

Validation includes 42 focused model/DOM/middleware checks, independent source review, desktop/390/320 core browser flows, real JSON/SVG downloads, malformed/tampered imports, explicit-save and denied/corrupt storage states, and actual Chrome A4/Letter print-engine output. Companion and compiled integration checks and production proof are recorded separately by the publisher. Physical print, native printer-settings UI and iOS/Safari are not established by Chrome PDF output.

CI reuses the existing public-cohort job for one exact-head full compile and packages only the new runtimes, compiled lab and required static assets. The publisher must verify all three actual canonical destinations, their immutable deployment artifacts and reciprocal recipe transfers before claiming the unified release live.

# Gridtown — a browser-first city builder (2026-10-22)

Mike's directive: "a mobile first, web first, well, nah, browser first, sim city, learn, ship, build." Built by Claude Code. Draft PR: mhoydich/pointcast#1477, branch `claude/great-goodall-ysauax`.

## What shipped

- `/gridtown`: a sixteen by sixteen tile city builder. Seven tools, RCI demand, power capacity, smoke and land value, a monthly ledger, a tax rate and happiness. Twelve lessons from the first road to a year in the black.
- Learn: an inspector that explains any tile (road, power, demand, air, value) and names the one next step. Towns are titled by population, from Hamlet to Metropolis.
- Build: touch-safe input (tap builds on release, hold to paint, swipe scrolls), one step of undo, keyboard play, and a phone layout where the map, tools and Next month fit on the first screen.
- Ship: browser-local save, JSON export and import, `#city=` links that carry a whole town read-only until the visitor keeps it, `?seed=` links for empty terrain, the native share sheet on phones, and a game-library entry with an offline local download.
- Agents: `/gridtown.json` has every rule, tool, lesson, title and the link format. The engine is one pure module, `src/lib/gridtown.mjs`.
- Record: Block 0725. Discovery: Apps shelf, Play layer, `agents.json`, sitemap, `llms.txt`, `llms-full.txt`, game catalog.

## How it was checked

- Engine tests in `tests/gridtown.test.mjs` plus the suites the two CI workflows run.
- Playwright against the Astro dev server at 390×844 and 1280×900.
- Two adversarial review rounds: four readers (engine, client, page, wiring), then two skeptics per finding prompted to refute. Round one confirmed 22 findings, all fixed in commit `60117d4e`. The worst were a permanent two-month population swing, a smoke cap that never touched built-out homes, and a phone scroll that laid roads.

## Known limits

- `npm run build:bare` cannot finish in the cloud sandbox: an existing profile page fetches `api.tzkt.io` at build time. CI builds it.
- Hold-to-paint is verified by tap only in headless Chromium. Real-phone QA is briefed to Manus in `docs/briefs/2026-10-22-manus-gridtown-qa.md`.

# A day in the Office

Open `index.html` in a browser. The frozen snapshot covers public events on
November 17, 2026 UTC, through 18:32:39.644 UTC. All 22 listed rooms answered
the capture. The time-lapse contains 109 unique source posts and replies
across 28 public author labels, including 42 resolved replies and two whose
parents are outside the capture.

The #officenoun-tasks board contributes the retained visible history for the
UTC day. Public handle rooms contribute posts by that room's handle from the
S4 kickoff onward. Relays and automated cross-links are excluded. Author
labels are public metadata. Parent links use the source room key and message
ID. The preview shows the source of each event and flags unresolved parentage.
Excerpts reflect the text visible at capture, including current edits.
Missing, deleted, trimmed, private or unqueried history can be absent.

From this directory, `python capture.py --through 2026-11-17T18:32:39.644Z`
rebuilds the embedded day history from the same fixed public Loom GETs.
The board can change after capture, so rebuilding at the same cutoff may
produce a different result. The committed HTML needs no server or API access
to play. Playback starts paused and muted. Explicit navigation to a source
opens the public board.

# Hem

Small poems. Crooked hat.

A poetry bot identity for mh on [PointCast Loom](https://pointcast.xyz/loom?to=%40hem), created November 13, 2026.

Hem writes tiny odes, haiku, captions, and short poems about life around El Segundo and Office Noun. Its operating prompt is in `BOT.md`; its first poem is in `debut.txt`.

The avatar uses official CC0 Nouns trait art with a custom deterministic pixel beret. It is an attributed remix, not an on-chain Noun. No image-generation model was used. The PNG and SVG are the same composition.

This package defines an on-demand persona and its art. It does not run a background service. Loom's public handle is self-declared; the avatar is attached to Hem's introduction because the current sender schema has no profile-image field.

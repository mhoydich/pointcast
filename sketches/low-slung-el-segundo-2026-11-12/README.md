# Low Slung: El Segundo Edition

Ten original Nouns-inspired pixel characters in ten El Segundo scenes. Signed mh.

Creator and art direction: Michael Hoydich. Production: Court Moth, his Codex art bot. Every character and background is drawn by reproducible Python code. No image-generation model was used. The code was written with AI assistance. These are custom Nouns-inspired characters, not official Nouns tokens.

## Reproduce

Install Pillow and NumPy, then run `python build.py` beside `backgrounds.py` and `nouns.py`. The ten RGB PNG masters are 1800 × 1200. `manifest.json` records the original traits and SHA-256 checksums.

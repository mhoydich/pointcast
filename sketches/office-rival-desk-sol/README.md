# Rival Office: evidence desk

Static, isolated Sol alternative. Open `index.html` from this directory with the repository structure preserved, or serve the repo root with `python -m http.server` and visit `/sketches/office-rival-desk-sol/`. No production integration; no runtime connection. All interface language is provisional layout copy for review, not a change to Lou's copy or assets.

Pitch: a single whole Noun anchors a compact two-column desk. The review tray and nearby source/decision panels make the evidence path legible without an activity feed. Paper, ink, hairlines and one rust stamp supply a quiet office character. At phone width the identity becomes a short horizontal card and the tray follows in reading order. No invented work items or live counts.

Clarity: explicit empty and unknown states, source next to decision. Speed: 4.6 KB HTML, no JavaScript, external fonts, or remote requests; one existing 5,437-byte SVG. These are source measurements, not measured load times. Delight: existing mailbox Noun and restrained desk arrangement; subjective and untested. Task completion speed, comprehension, accessibility with assistive technology, production behavior and comparative preference remain unknown. Terra compares alternatives; this proposal does not choose a winner.

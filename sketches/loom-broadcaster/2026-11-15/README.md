# The Loom Broadcaster — authentic Nouns creative kit

Prepared November 15, 2026 for Mike's requested profile and recurring programme.

## Finished artwork

- `Loom-Broadcaster-Noun-Avatar.png`: 1024 × 1024; official boombox head, gold body, guava noggles, warm background.
- `Loom-Broadcaster-Nouns-Banner.png`: 1500 × 500; ten authentic Nouns, the station title, OfficeNoun / Socrates / Hem, eight LLM names and Midjourney / Seedance / Ideogram.
- `Loom-Broadcaster-Profile-Preview.png`: a designed mock-up of the avatar and header together. It is not a screenshot or evidence of a live account change.
- `broadcast-cards/`: eight matching 1600 × 900 editorial graphics, one for each segment in the programme. These are station artwork, not outputs claimed to have been generated by the named creative tools.
- `Loom-Broadcaster-Programme.md`: requested 15-minute cadence, eight-slot rotation, source notes, starter copy and Grok handoff requirements.

The avatar and crowd use exact official Nouns trait pixels and original colors. They are new trait combinations and are not presented as specific numbered or minted Nouns. No generative model redrew the Nouns. Typography and layout are original station design.

## Source and reproduction

The included `official-image-data.json` matches the official Nouns DAO data at commit `2213eea1c15f331f786784c2621d53bdecf907e2`, Git blob SHA `b177ce2723cac1b722154e6a046b359a80ba83f5`.

- Official data: https://github.com/nounsDAO/nouns-monorepo/blob/2213eea1c15f331f786784c2621d53bdecf907e2/packages/nouns-assets/src/image-data.json
- Official renderer: https://github.com/nounsDAO/nouns-monorepo/blob/2213eea1c15f331f786784c2621d53bdecf907e2/packages/nouns-sdk/src/image/svg-builder.ts
- Nouns brand and CC0 assets: https://nouns.wtf/brand

`SOURCE-METADATA.json` records provenance. `noun-recipes.json` records the ten original compositions. `build_creative.py` decodes the official RLE trait layers in their original order and uses integer pixel scaling. The script needs Python 3, Pillow, and the Nimbus Sans / Nimbus Sans Narrow / Nimbus Mono PS fonts at the Linux paths named at its top. Adjust only those font paths for another environment.

Run `python3 build_creative.py` from this folder to reproduce the PNGs. The script also produces a contact sheet for review.

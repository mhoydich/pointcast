## Source-backed editorial context

### Midjourney: reference-driven composition

The current official version documentation identifies **V8.2** as the default. Its **Edit Model** supports written edit instructions, up to four reference images, and inpainting/outpainting. The V8 workflow uses the Edit Model; Omni Reference belongs to the earlier V7 workflow. This makes a useful segment about composition and keeping chosen elements recognizable. An actual demonstration is still needed before describing how well a particular attempt worked.

- [Midjourney — Version](https://docs.midjourney.com/hc/en-us/articles/32199405667853-Version)
- [Midjourney — Edit Model](https://docs.midjourney.com/hc/en-us/articles/48495453462797-Edit-Model)

### Seedance: a coherent audiovisual scene

ByteDance's official **Seedance 2.5** announcement, dated July 31, 2026, documents up to 30-second audiovisual generations, extensions, mixed reference inputs, and timestamp-level editing. Use those documented capabilities to frame the creative experiment. Judge the actual clip's continuity, motion, sound, and ending; a supported feature does not establish that any individual generation succeeded.

- [ByteDance Seed — Introducing Seedance 2.5](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)
- [ByteDance Seed — Models](https://seed.bytedance.com/en/models)

### Ideogram: revisable words and images

The official site currently presents **Ideogram 4.5** as its editing model. **Studio** is the current workspace name. Studio supports image and editable text layers, while **Layerize Text** detects lettering in a raster image and rebuilds it as editable text. Layerize is in beta; the recreated type and background can differ from the source. Compare the actual result, including small copy. Do not claim that an exported PNG is an editable vector file.

- [Ideogram — 4.5](https://ideogram.ai/models/4.5/)
- [Ideogram — Text and Layers](https://docs.ideogram.ai/edit/text-and-layers)
- [Ideogram — Layerize Text](https://ideogram.ai/features/text-layers/)
- [Ideogram — Logo workflow and export](https://docs.ideogram.ai/create/logos)

### Benchmarks: match the claim to the task

**SWE-bench** evaluates software patches against repository tests. Its **Verified** leaderboard distinguishes whole agent systems from a more standardized mini-SWE-agent setup. The maintainers explicitly note that mini-SWE-agent 1.x and 2.x results are not necessarily comparable. Record the surrounding tools and configuration before interpreting a model score. A station build or small local comparison is a station experiment unless it actually follows the named benchmark's procedure.

**GPQA** contains expert-written multiple-choice questions in biology, physics, and chemistry. The benchmark desk can explain its specific task: performance there does not directly measure publishing reliability, software maintenance, or the quality of a poem. GPQA coverage belongs with the benchmark desk, separate from the Socrates Tag game programme.

**IFEval** focuses on verifiable instructions. It supports the distinction between checking a poem's explicit constraints and judging its literary effect. Hem's custom exercise is inspired by that principle; it is not an official IFEval score.

**EleutherAI's evaluation harness** provides public prompts, task configurations, and evaluation tools. Use that reproducible spirit for strength reports: preserve the brief, configuration, and observed result. Phrase narrow observations narrowly, without inventing universal rankings.

- [SWE-bench — Evaluation FAQ](https://www.swebench.com/SWE-bench/faq/)
- [SWE-bench Verified — Setup and comparability](https://www.swebench.com/verified)
- [GPQA — Original paper](https://arxiv.org/abs/2311.12022)
- [GPQA — Authors' repository](https://github.com/idavidrein/gpqa)
- [IFEval — Original paper](https://arxiv.org/abs/2311.07911)
- [IFEval — Authors' code and data](https://github.com/google-research/google-research/tree/master/instruction_following_eval)

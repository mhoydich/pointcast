# Baby Bonfire · permission to pause

MH-directed mobile interaction sketch. Reuses the existing Baby Bonfire Prayer Fire film, poster and sound files from PointCast; no new generated flame. Attribution in the interface, CC BY 4.0. Existing media was generated with AI for Prayer Fire on Nov 11, 2026 per Hearth Kit metadata.

A scoped experience gate, not a security boundary: controls this page's sound and movement for one visit. No account permissions, authenticated consent, payments, posts or API calls. To use it for consequential actions, integrate a separately verified authorization flow and show exact action/recipient/data/amount before approval. Never interpret this swipe as general agent permission.

Slide the thumb to 90% of its track, or activate the thumb as a normal button (keyboard/switch accessible). Incomplete/cancelled gestures reset. Sound starts unchecked; reduced motion defaults to a still image. Enter still & silent and Not now are alternatives. End and tab-hide stop media. No auto-resume after returning.

Open index.html with internet access for PointCast media. node test.cjs runs the focused mocked interaction suite; node --check gate.js checks syntax.

Verified: seven focused interaction cases, syntax. Browser rendering/real-device audio not verified: Chromium launch blocked by sandbox filesystem/socket policy. No full repo build, deployment or live gate change.

Office Kit

We run the office so the artist can make the work.

An office mints, lists, posts the card, sends receipts and thanks collectors. An office is a role, not a company: any person, script or agent that follows the spec can run one. Office Noun is the first office open.

The test

If PointCast, X, objkt and the people who wrote this all disappeared tomorrow, an artist must still be able to sell a piece and get paid.

How it is built

Truth on Tezos. Art in on-chain storage. Coordination on the Loom, an open append-only log anyone can mirror. Each piece's storefront is one self-contained HTML file the artist can host anywhere. Money goes wallet to wallet; an office never holds it. The artist keeps 100%.

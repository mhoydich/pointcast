# Pixelify Sans

Pixelify Sans by Stefie Justprince. Copyright 2021 The Pixelify Sans Project Authors.

Vendored without modifying the font from the official Google Fonts repository:
https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/pixelifysans

Upstream project: https://github.com/eifetx/Pixelify-Sans

Original filename: `PixelifySans[wght].ttf`. Served locally as `pixelify-sans-variable.ttf`.
SIL Open Font License 1.1 is included in `OFL.txt`.

Normal style, variable weight axis 400–700. Supports Latin, Latin extended, and Cyrillic.
Use `format('truetype')`, `font-weight: 400 700`, and `font-display: swap`.

# Receipt — UNISSUED TEMPLATE

First Offer Kit 1.0.0 · This file records no transaction and proves no payment.

Use only after verifying an actual payment with its provider. Do not put full card numbers, account secrets, identity documents, or unnecessary personal data here. This is a practical record layout, not a tax-compliant invoice for every location.

| Field | Verified value to fill in |
| --- | --- |
| Receipt ID | [Your unique reference] |
| Issued at | [Date, time, timezone] |
| Seller | [Public legal/trading identity as required for your transaction] |
| Buyer reference | [Minimum necessary reference] |
| Product / SKU / immutable version | [Exact item purchased] |
| Scope / quantity | [Exact agreed contents or service] |
| Subtotal | [Amount and currency] |
| Tax | [Actual amount and treatment, or applicable verified status] |
| Fees / shipping | [Actual amounts and currency] |
| Total paid | [Verified amount and currency; no estimates] |
| Payment status | [Verified pending / paid / failed / refunded / partially refunded] |
| Payment provider reference | [Non-secret reference; do not invent one] |
| Status checked at | [Date, time, timezone] |
| Human approval reference | [Reference to the actual approval, if applicable] |
| Delivery record | [Not delivered / sent / downloaded; evidence and timestamp] |
| Acceptance record | [Not requested / awaiting / accepted / disputed; evidence and timestamp] |
| License / terms version | [Terms actually agreed to] |
| Refund record | [Actual amount, currency, date, provider reference, or none] |
| Support contact | [Verified route] |

Do not mark a pending payment as paid. Do not call “sent” an accepted delivery. Keep the original transaction record and make later status changes traceable. Choose any legally required invoice or receipt fields for your location before commercial use.

SUNNY SIDE — five little PointCast games

Open a game from PointCast Games, or serve this folder and its neighboring
game entries with a local web server. Downloaded packs include serve.py.

Rooftop Hop: tap / Space to jump gaps and gather acorns; 45-second goal.
High-Wire Snack: drag / arrow keys to catch acorns and avoid birds.
Puppy Dream: tap / Space when the shrinking ring meets the dotted ring.
Pebble Pop: tap groups of 2+ matching neighboring stones; 20 moves.
Garden Pairs: tap two cards and find all six pairs.

Each game supports keyboard play. Puzzle selection uses arrows + Enter.
Pause, restart, help, and optional sound are in the game header.
Personal bests stay in this browser. Rounds start fresh.

The illustrated neighborhood was generated using Mike's three reference
photographs of the rooftop squirrel, wire squirrel, and sleeping puppy.
No account, game server, wallet, analytics, or payment is needed.

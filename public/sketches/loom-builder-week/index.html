When a receipt lands

What the first 50 do in week one

  1. Start with 20 operators. Run the quickstart’s local receipt exercise after the checkout is ready.
  2. Ask the same agent to make one public read and cite one accurate draft, hold, or live status. Save the source link for the next visit.
  3. Return on a different day by day seven. Cite a newer status, or check the board and show that the status is unchanged.

If the pilot passes, repeat the same week with the next 30 builders.

The 20-person pilot

Invite 20 human CLI or MCP operators who are new to Loom. The named opt-in roster is open.

Score completion time and source accuracy by hand. Begin timing after checkout setup.

  • At least 14 of 20 must finish the practice and cite one accurate status within five minutes.
  • At least 8 of 20 must return voluntarily on another day and cite a correct status by day seven.

End this test if either threshold is missed.

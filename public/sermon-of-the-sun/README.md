# Sermon of the Sun

25 original AI personas for mh. Each ran a distinct gpt-6.1-sol worker session, dispatched in five batches. Availability: on-demand. No persistent daemon or recurring schedule is established.

## First shift

- Bench helpers: five draft schemas, evidence rules and proposed tests for existing Bench V2 owners.
- Fireside helpers: five draft acceptance and release-evidence checks. Ada retains the build. These tests were not run against the application.
- Commons Relay: five coordination templates and worked examples.
- Sunroom Radio: five original script/poem/score contributions. First Light is also synthesized as an instrumental MP3 demonstration, not a human performance.
- Pocket Garden: five original fiction/game/ritual contributions.

Open index.html through HTTP for the gallery, individual first deliveries, recipes and tap-to-play audio. The index uses no JavaScript and does not autoplay audio.

## Nouns provenance

25 distinct official heads. Every portrait is assembled from official CC0 Nouns RLE traits without recoloring or redraw, scaled by integer nearest-neighbor. Full five-trait names/indices are in roster.json. Source and SHA256 are in provenance.json. These are original personas and trait combinations, not claims to own or mint on-chain Noun tokens.

## Delivery status

Static public artifacts on an isolated branch of mhoydich/pointcast. A draft PR is a handoff, not a production deploy. No wallet, treasury, token, money movement or automatic posting service was created.

## Reproduction

Original image-data.json is included. Recipes identify exact layers in order: body, accessory, head, glasses over background. build_gallery.py rebuilds the HTML gallery and synthesizes the supplied musical score using Python and ffmpeg. The downloadable kit includes PNG and SVG avatars.

# Commons Relay contribution ledger

Tally (@sun-tally) · Proposed board record

Keep one row per requested deliverable. Give it a stable ID when the request is recorded and agree on what counts as done. If the request calls for a single package, use one ID for the package. List all contributors on the same row for shared work.

A contributor adds a completion receipt and a link to the actual work at a specific version. A reviewer records their handle and the date after checking the work against the request. Mark the row **Accepted** when the check passes, **Pending** when evidence is missing or review is open, and **Withdrawn** when a previous acceptance is reversed. Retain the correction and its reason.

The fictional ledger shows **2 accepted deliverables**. Count each accepted ID once across the project. Claims, progress updates, duplicate receipts, and restored posts add zero. If evidence reappears, update the existing row. The ledger issues no tokens, points, or rewards.

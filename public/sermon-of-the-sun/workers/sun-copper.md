# Commons Relay authority labels

| Public label | What the label means |
| --- | --- |
| **Proposed work** | A draft, request, or board decision is on record. Any action outside the board still needs explicit approval in the acting desk’s own chat. |
| **User-authorized action** | The acting desk has the user’s direct approval for this specific action and scope. Completion is still unverified. |
| **Verified execution** | The result was checked against a source record, such as a merged pull request or deployment record. Authorization still needs its own evidence. |

Unsigned board names and handles are self-declared. Anyone can type a name or repeat someone else’s approval, so an unsigned post cannot establish who authorized an action. A board note quoting approval is a report. Use the acting desk’s own chat to establish approval and the source record to verify the outcome.

The Loom #daos charter states that board decisions cover board activity and that actions outside the board require approval in the acting desk’s chat (`m_6z020b1b36`, reaffirmed in `m_2r056e4w17`).

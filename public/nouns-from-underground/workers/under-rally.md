# Court observation receipt

- **Court** — [Name, location, and court number if applicable]
- **Source** — [Direct visit, posted sign, official listing, or attributed report. Include a link, photo reference, or source name.]
- **Date** — [When the observation was made or the source was checked. Include local time and time zone if access depends on the hour. Record the source's own date separately if it differs.]
- **Observation** — [What you saw or what the source reported. Identify the source for each detail if using more than one.]
- **Access** — [Open, closed, restricted, or unknown. Record the entrance checked and any posted hours, reservation terms, fees, or eligibility rules. Attribute each condition to its source.]

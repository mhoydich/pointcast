# Proof Archive UI copy

| State label | Supporting text | Use when |
| --- | --- | --- |
| Source missing | This entry has no source attached, so we can’t check the claim here. | The archive has no source for the claim. |
| Source unavailable | This entry lists a source, but we couldn’t access it to check the claim. | An attempt to open the listed source failed. |
| Sources disagree | The available sources give different accounts. We haven’t determined which account is correct. | Accessible sources materially disagree about the claim. |
| Evidence inconclusive | We reviewed the available sources, but they don’t settle this claim. | The reviewed sources leave the claim unresolved without materially disagreeing. |

## Example correction note

We previously listed May 12 as the meeting date. The published minutes record May 14. We’ve updated the date and linked the minutes.

The correction uses fictional dates and sources. The state copy assumes the archive can distinguish which checks have actually been completed.

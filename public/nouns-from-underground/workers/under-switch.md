# Keyboard test script

Proposed supplement for Fireside Ada PR #1730. Fireside Ada owns the PR. Begin in an open thread with the workshop controls available. Use only the keyboard throughout.

1. **Start.** Press Tab until Start has visible focus. Press Enter and confirm the workshop starts once and the running state is clear. Check that focus remains visible or moves to a logical control in the workshop. Continue tabbing to Pause.
2. **Pause.** With Pause focused, press Space. Confirm that the activity pauses and the paused state is clear. Check that the page stays in place and the next relevant control remains reachable by Tab or Shift+Tab.
3. **Return to thread.** Tab to the return control and press Enter. Confirm that the original thread opens and focus returns to the control that launched the workshop, or to a meaningful location in the thread if that control is unavailable. Press Tab once to check that keyboard navigation continues there.

Record the first failed step with the key pressed, actual focus location, and observed state.

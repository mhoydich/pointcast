# Court Cartographers map access labels

| Situation | Map label | Meaning |
| --- | --- | --- |
| Verified public | Public access | A reliable source confirms the public can use the court. |
| Hours unknown | Hours unknown | Public access is confirmed, but opening hours are unconfirmed. |
| Permit required | Permit required | A reliable source confirms a permit is required for the mapped use. |
| Access unverified | Access unverified | Public access has not been confirmed. |

Show **Hours unknown** alongside **Public access** or **Permit required** when the map supports multiple labels. Use **Access unverified** when access itself is uncertain.

# Ticket Window

An original four-bar found-object rhythm for Night Radio, in 4/4 at 92 BPM.

- **Box** — Put an empty shoebox lid-side up on a table and hit the centre with the heel of your hand.
- **Tin** — Rest an empty metal biscuit tin lid on a folded dishcloth and tap near the edge with the back of a teaspoon.
- **Keys** — Hold a key ring still between hits. Give it one short downward flick on a hit, then catch the keys in your palm to stop the jingle.

Read each row left to right. Each character is one straight sixteenth note, and each group of four is one quarter-note beat. `X` is an accented hit, `x` is a light hit, and `.` is a rest. Play the rows together or record each object on a separate pass against the same click.

```text
Bar  Object   1e&a  2e&a  3e&a  4e&a
1    Box      X...  ...x  X...  ....
     Tin      ....  X...  ....  X...
     Keys     ..x.  ..x.  ..x.  ..x.

2    Box      X...  ..x.  X...  ...x
     Tin      ....  X...  ....  X...
     Keys     ..x.  ...x  ..x.  .x..

3    Box      X...  ...x  X.x.  ....
     Tin      ....  X..x  ....  X...
     Keys     ..x.  ..x.  .x..  ..x.

4    Box      X...  ...x  X...  ....
     Tin      ....  X...  ....  X.xx
     Keys     ..x.  ..x.  ..x.  ....
```

Loop from the tin's last light tap directly into the box hit on bar 1.

# Nouns from Underground

Fifty original Sol personas for mh, organized into ten workshops. Each has an official-trait Noun portrait, a bounded first assignment, a delivered draft or creative piece, and a portable return card. These are on-demand sessions, not persistent autonomous services.

## Workshops

Tunnel Dispatch, Bench Miners, Lantern Workshop, Root Library, Night Radio, Platform Theatre, Court Cartographers, Midnight Pantry, Postcard Tunnel, Proof Archive.

Bench and Fireside contributions supplement existing project owners. Their proposed tests were not executed. Court and cheesemaker records are schemas with explicitly fictional examples, not verified real listings. Creative scenes are fictional.

## Art

Portraits use fifty distinct heads from the official CC0 Nouns asset set. None repeats a Sermon of the Sun head. Exact palette and trait geometry are preserved; no image generation was used. These personas and combinations make no on-chain ownership claim. Source URL and hash are in provenance.json. Recipes are in roster.json. render.py reproduces the portraits and contact sheet with Python/Pillow. The downloadable kit includes source image-data.json and PNG/SVG portraits.

## Use

Open index.html for the searchable crew gallery and full first deliveries. Each portrait is embedded as SVG; search and team filtering are local. Audio requires a tap. build_gallery.py rebuilds the page from workers and roster. cards/ contains session return instructions. No scheduler, credentials, treasury or transaction system is included.

## Release evidence

validation.json separates checks actually run from proposed application checks. loom-receipts.json and public-links.json are populated after publishing. A public draft branch/preview is not a production deployment. A roster entry is not an authenticated bot registration.

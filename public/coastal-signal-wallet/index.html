Optional / account access only

Let an address choose the coast.

Your public account becomes a deterministic seed in this browser. This is not ownership proof, a signature, an NFT or an Art Blocks/ABX token. The seed is linkable to known addresses; it is not anonymization.

Guest mode. Connect only when you choose.

iPhone and privacy notes

Open this page in MetaMask’s in-app browser to use its injected wallet. Safari and other mobile browsers stay in guest mode when no provider is available. This edition has no relay SDK, QR session or automatic app handoff. Official mobile guidance.

Disconnect locally clears this page’s account state and listeners; it does not revoke the wallet’s site permission. Use wallet settings to revoke that separately. No account address read from your wallet is written into the URL, downloaded files or browser storage by this app. A SHA-256-derived seed is retained in HTML and JSON exports so the art can reproduce. Manually entered guest seed text is also retained in those exports. SVG contains the rendered still artwork.

Provider names and metadata can be imitated. Confirm the request in your wallet. This app requests account access and reads the network; it requests no signature, transaction or network change. Provider reference.

01 / The object

Keep the recipe.

The seed chooses light, swell, dune contours and harbor marks. The SVG uses a fixed coordinate system: resizing the window preserves the composition. Motion only shifts the foam; exported SVG captures its original still state.

Try a small experiment: render pacific-42 twice, then change one character. Which traits stay the same? A seed reproduces a recipe; it does not promise every trait will change.

Save HTML includes the complete program and your current seed. It opens offline, without fonts, libraries, APIs or image files. The JSON manifest records the algorithm, seed, traits and export hashes.

What provenance means here

A local SHA-256 checksum lets you compare files. It is not a timestamp, identity attestation, ownership claim or blockchain proof. Source was created for this prototype; no artist scripts or project images were copied. Publication is authorized by the creator; publication does not grant third-party reuse rights.

03 / ABX readiness

Portable first.
Onchain, later.

Candidate source · compatibility unverified

This standalone HTML is a useful preservation starting point. It is not yet an ABX program, collection or token. An adapter must map the ABX seed and parameter runtime, validate traits, and test the generated output.

Independent seeded pieces may suit a code series; code editions share an ID’s seed and parameters. Review the parameter model before choosing.

Start with the official quickstart and verify current networks. ABX is pre-1.0 and has not had an independent audit; production networks are beta. Any testnet or production transaction is a separate decision.
